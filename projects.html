EnStyle Tool

Nstyle will serve as an online extension, designed to enhance
the shopping experience across various online clothing platforms.
Upon selecting a clothing item on a particular brand's site,
users will be presented with a pop-up that displays their
recommended size based on the measurements they provided
during the initial setup. These measures are stored in a
database and need only be entered once, though they can be
updated as necessary. Each time the user engages with a
partnered shopping platform, the pop-up will automatically
appear, offering tailored sizing recommendations specific to
the selected brand. The website for this project has been
completed. However, it continues to be an ongoing project. The
inspiration behind EnStyle came from the common experience of
online shoppers buying clothes in their size only to realize the
brand's measurements did not match their expectations.

Budgeting App

This budgeting app serves as a personal financial assistant,
designed to help users who may struggle with budgeting or
financial calculations. It includes several key features, such as:
budget planning based on the well-known 50/30/20 rule, future
value calculations for savings or investment accounts, life
insurance needs estimation, and a simple interactive game
that educates users on essential financial concepts. The
inspiration for this app came from the significant number of
individuals who lack financial literacy due to limited access
to educational resources. This app aims to promote financial
awareness and empower users to make informed financial decisions.

Calculator App

This calculator app is built with Python and is designed to
perform simple mathematical operations, allowing users to
quickly complete calculations. The program prompts the user to
enter two values and choose an operation: addition, subtraction,
division, exponentiation, or modulo. Once all three inputs are
provided, the app performs the selected operation, always using
the first value as the base. The result is then displayed to the
user, who is asked whether they would like to perform another
calculation. If the user chooses not to continue, the program
exits. Input validation is built into the app to ensure that
all user entries are valid, helping prevent errors during execution.
